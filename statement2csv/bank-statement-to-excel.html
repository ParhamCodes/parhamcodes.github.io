How to get a bank statement PDF into Excel or Google Sheets

Banks publish statements as PDFs because the format preserves a fixed page layout. Excel and Google Sheets need something different: one transaction per row, with separate fields for the date, description, amount, and balance. Copying a table from a PDF often mixes columns or drops rows, so a CSV conversion is usually more reliable.

1. Download the right statement

Sign in to your bank and download the original monthly or account statement as a PDF. Do not use a screenshot, phone photo, or scan of a printed page. The PDF should contain real text. Check by selecting a transaction description in your PDF viewer and copying it into a text editor. If the words paste correctly, the file is likely suitable.

If you cannot select text, the statement is image-only and needs OCR. Statement2CSV does not use OCR because it performs the conversion locally in your browser without sending the file to a server.

2. Convert the PDF to CSV

Open Statement2CSV, choose the PDF, and wait for the transaction preview. The tool reads the PDF locally with JavaScript and extracts the date, description, transaction amount, and running balance when one is present. Nothing in the statement is uploaded. The first 15 rows are free, which is enough to check whether your bank's layout is being interpreted correctly.

Before exporting: compare the preview with the original PDF. Check at least one debit, one credit, and a row with a balance. A payment should not accidentally appear as the running balance.

3. Import the CSV into Excel

  1. Open Excel and choose Data > From Text/CSV.
  2. Select the downloaded CSV file.
  3. Confirm that the file origin and encoding preserve the transaction descriptions.
  4. Set the delimiter to Comma if Excel does not detect it.
  5. Review the preview, then choose Load.

Using the Data import flow is safer than double-clicking the CSV because it lets you inspect how Excel will split and type the columns before adding them to a workbook.

4. Import the CSV into Google Sheets

  1. Open a new or existing spreadsheet.
  2. Choose File > Import > Upload.
  3. Select the CSV and choose whether to create a new sheet or replace the current one.
  4. Leave the separator on automatic detection, or choose Comma if the preview shows one long column.
  5. Select Import data.

Check the spreadsheet before using it

Look at the amount and balance columns first. The amount is the change caused by one transaction, while the running balance is the account total after it. Withdrawals should normally be negative. If those columns are reversed, totals and cash flow calculations will be wrong.

Also check dates before sorting. A value such as 04/07/2026 can mean April 7 or July 4 depending on the bank's format and your spreadsheet locale. The converter keeps the bank's printed date format, so set the spreadsheet column to the intended locale if it interprets dates incorrectly.

If every row appears in one column, the delimiter was not detected. Reimport the file and choose comma. If descriptions containing commas split into extra columns, use the import command rather than pasting raw text, since the CSV correctly quotes description fields.
